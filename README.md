# MindLink
串口通信调试工具，支持过滤数据。
由于工作需要自己开发的串口调试工具。 具备过滤串口信息的功能，市面上也有优秀的软件，但是收费，而且使用起来不太习惯，因此自己做了一个。 本来过滤信息打算加变色显示，但是会影响执行效率，界面由卡顿，所以去掉了。 功能有限，主要目的是过滤信息，仅用来参考、试用，水平有限，不喜误喷。 欢迎交流
